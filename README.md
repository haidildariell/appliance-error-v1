# The Funniest Honest Appliance Error

One honest error line a washing machine could plausibly show: "Error 04: I ate one sock. I will now vibrate until you forgive me."

Entry for the make.fun bounty [The Funniest Honest Appliance Error](https://make.fun/bounty/u-xvader-the-funniest-honest-appliance-error-adec4450) — a single line of at most 200 characters, the funniest honest error message an appliance could show.

## How it works

`main.py` writes the error line to `/output/entry.txt`. Python stdlib only, deterministic, no network, no external files.
